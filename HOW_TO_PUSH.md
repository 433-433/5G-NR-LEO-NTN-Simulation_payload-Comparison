# How to push this to GitHub

Everything in the zip is ready to go — a clean working tree with `README.md`, `LICENSE`, `.gitignore`, `CITATION.cff`, your code, your results, and a `docs/` folder. No `.git` directory yet, so you get to make the first commit under your own name.

## 1 · On GitHub (in the browser)

Fill in the "Create a new repository" form you had open:

- **Owner**: your account
- **Repository name**: `5g-nr-leo-ntn` (or whatever you prefer; short, lowercase, hyphenated)
- **Description**: *Waveform-level 5G NR simulation comparing transparent and regenerative LEO payload architectures — ICAST 2026 Paper 110.*
- **Visibility**: **Public** (recommended — for citations and reproducibility) or Private
- **Add README**: **Off** — we already have one in the zip, we don't want GitHub overwriting it.
- **Add .gitignore**: **No .gitignore** — we already have one.
- **Add license**: **No license** — we already have an MIT `LICENSE` file.

Click **Create repository**. GitHub shows you a page with a URL that looks like:

```
https://github.com/<your-username>/5g-nr-leo-ntn.git
```

**Copy that URL** — you'll paste it in step 3.

## 2 · On your machine

Open a terminal (Git Bash on Windows; Terminal on Mac/Linux). Then:

```bash
# unzip the project somewhere sensible
cd ~/Documents            # or wherever
# (extract the zip here; you should now have a folder like Phase1_v3_FINAL_2/)
cd Phase1_v3_FINAL_2      # cd into whatever folder name the zip extracted as

# tell git who you are (only needed the first time, ever)
git config --global user.name  "Lawerteh Isaiah Amatey"
git config --global user.email "isaiahanim20@gmail.com"

# start a git repository here
git init -b main

# stage every file that .gitignore allows
git add .

# make the first commit
git commit -m "Initial release: ICAST 2026 Paper 110 — 5G NR LEO NTN simulation"
```

## 3 · Push to GitHub

Replace the URL below with the one GitHub gave you, then:

```bash
git remote add origin https://github.com/<your-username>/5g-nr-leo-ntn.git
git push -u origin main
```

GitHub will ask you to authenticate. On modern systems, the browser opens and you log in; otherwise it asks for your **personal access token** (not your password — GitHub stopped accepting passwords in 2021). If you don't have a token, follow these two short steps:

1. Go to https://github.com/settings/tokens → *Generate new token (classic)*.
2. Give it any name, tick the **repo** box, click *Generate*, copy the token, paste it into the terminal when git asks for your password.

That's it. Reload the GitHub page and your code is there.

## 6 · If anything fails

- **"fatal: not a git repository"** — you forgot to `cd` into the project folder before `git init`.
- **"Permission denied (publickey)"** — you used the SSH URL by accident. Use the HTTPS URL (the one with `https://`), not the one with `git@`.
- **"Updates were rejected because the remote contains work that you do not have locally"** — you ticked *Add README* / *Add .gitignore* / *Add license* on the GitHub form. Easiest fix: delete the GitHub repo (Settings → Danger Zone → Delete this repository) and recreate it with all three options turned off, then push again.
- **Something else** — paste the error at me and I'll diagnose it.
